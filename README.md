# Mission Tracker

Aplicativo de acompanhamento de pesquisadores com data batismal, construído
**100% dentro do Google Sheets** com Google Apps Script — pensado para uso no
**celular** (app Google Sheets), sem HTML Service, Sidebar, Dialog ou menus
personalizados.

O código-fonte e a documentação completa estão em [`mission-tracker/`](./mission-tracker/).

- Arquitetura, decisões e modelo de dados: [`mission-tracker/README.md`](./mission-tracker/README.md)
- Instalação: rode a função `setupApp` uma vez no editor do Apps Script.
