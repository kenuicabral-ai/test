# Mission Tracker

Aplicativo Google Apps Script para acompanhamento de pesquisadores com data batismal dentro do Google Sheets.

## Instalação

1. Abra o projeto no editor do Apps Script vinculado à planilha.
2. Copie os arquivos `.gs` e `appsscript.json` para o projeto.
3. Execute `setupMissionTracker()` uma vez para criar abas, validações, cards, proteções e base inicial.

## Uso

- O LD usa `🏠 Home` e `📱 Registro`.
- O LZ usa `📊 Dashboard Zona`.
- A base canônica fica em `Base`, oculta e protegida.
- O histórico fica em `Histórico`, oculto e protegido.

Veja `ARCHITECTURE.md` para as decisões técnicas.
